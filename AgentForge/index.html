THE IMPORTANT DISTINCTION

A forecast is not a measurement.

TokenBudget counts the submitted input using a heuristic by default, then models possible model calls, context growth, output and retries.

  • ✓ 10,000 deterministic seeded samples
  • ✓ Cumulative and peak-context limits
  • ✓ Human approval gates stay intact
  • ! No real-run P90 calibration yet
WHAT THIS DEMO DOES

It compares your chosen limit with one published development sample. It does not call a model or execute the .NET engine in your browser.

03 / APPROACH

Explain the plan. Keep the control.

The core does analysis; your application decides whether, when and how to execute.

01

Describe

Supply a Markdown work plan with milestones, dependencies and approval points.

02

Forecast

Inspect read-only repository metadata and model cumulative and peak-context usage.

03

Decide

Apply explicit caps and risk tolerance. Keep the human approval boundary visible.

04

Compare

Import recorded Codex usage later to measure error and guide future calibration.

≠
A HARD BOUNDARY

Analyzing a plan does not authorize running it.

By default, AgentForge’s TokenBudget preflight performs no agent execution and no provider upload. Optional LLM review requires explicit consent. Forge planning primitives also leave persistence and side effects to the calling application.
